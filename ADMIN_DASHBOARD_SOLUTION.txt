PROBLEM: Admin (IT) and Admin (Non-IT) needed same dashboard, different features
SOLUTION: Use same component with conditional props

================================================================================
IMPLEMENTATION
================================================================================

Component: CompanyDashboard
Parameter: showLocationTracking (boolean)

When showLocationTracking = true:
  ✓ Shows stats cards
  ✓ Shows employee live locations
  ✓ Shows HR manager locations
  ✓ Shows refresh button
  
When showLocationTracking = false:
  ✗ Hides stats cards
  ✗ Hides employee live locations
  ✗ Hides HR manager locations
  ✗ Hides refresh button
  ✓ Shows basic admin dashboard

================================================================================
ROUTING LOGIC
================================================================================

In Dashboard.jsx:

case ROLES.ADMIN:
case ROLES.SUPER_ADMIN:
  // Both use same component
  // Prop determines what shows
  return <CompanyDashboard showLocationTracking={companyType === 'non-it'} />

Result:
  - If companyType = 'it'      → showLocationTracking = false (location hidden)
  - If companyType = 'non-it'  → showLocationTracking = true (location shown)

DATA LOADING
================================================================================

When showLocationTracking = false (IT Admin):
  ✗ Does NOT query employee_locations table
  ✗ Does NOT query HR manager locations
  ✓ Sets empty arrays for locations
  ✓ Sets empty stats
  ✓ Saves database queries

When showLocationTracking = true (Non-IT Admin):
  ✓ Queries employee_locations from database
  ✓ Queries HR manager locations from database
  ✓ Calculates stats (total employees, online count, HR count)
  ✓ Loads all location data

Result: Better performance! Only queries when needed.
