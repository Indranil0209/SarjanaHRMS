WHAT THE TOGGLE DOES:
================================================================================

ENABLED (Green):
  → Shows employee's live location
  → HR managers can see location
  → Shows location history
  → Shows last update time
  → Allows viewing on Google Maps

DISABLED (Gray):
  → Hides all location sections
  → Shows "Location Tracking Disabled" message
  → Tells user how to enable it
  → Privacy-first design (default: disabled)

================================================================================
DATABASE TABLE SCHEMA:
================================================================================

Table Name: user_settings
Columns:
  - id (auto-generated)
  - user_id (links to users table)
  - location_tracking_enabled (true/false)
  - created_at (timestamp)
  - updated_at (timestamp)

Default: false (disabled for privacy)
