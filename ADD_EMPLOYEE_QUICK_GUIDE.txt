IMPORTANT: EMPLOYEE ID
━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  The Employee ID you enter is what the employee will use to register!

Example:
├─ HR enters Employee ID: EMP123
└─ Employee must use: EMP123 (exactly, case-sensitive)

Best Practices:
✅ Use consistent format: EMP001, EMP002, EMP003
✅ No spaces (use EMP-123 or EMP_123 if needed)
✅ Make it easy to remember and type
✅ Keep a record of assigned IDs

❌ Don't:
❌ Use random complex IDs
❌ Reuse IDs from terminated employees
❌ Include special characters that are hard to type

TROUBLESHOOTING
━━━━━━━━━━━━━━━

Problem: Can't see "Add User" button
Solution: ✓ Make sure you're logged in as HR Manager
         ✓ Check your role has proper permissions

Problem: Form won't submit
Solution: ✓ Fill ALL required fields (marked with *)
         ✓ Check email format is valid
         ✓ Employee ID must be unique

Problem: Employee still gets "No record found" error
Solution: ✓ Wait a few seconds for database to update
         ✓ Double-check Employee ID matches exactly
         ✓ Verify Company Code is correct
         ✓ Refresh the employee registration page
